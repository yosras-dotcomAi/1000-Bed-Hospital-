# Hospital Bed Capacity Case Study

## 📋 نظرة عامة
دراسة حالة تحليلية لمستشفى وهمي (1000 سرير)، بتركّز على سعة الأسرّة والأداء التشغيلي، بهدف بناء بورتفوليو يوضح مهارات التحليل الاستراتيجي في الرعاية الصحية.

## 🎯 الهدف
تحليل معدلات إشغال الأسرّة عبر الأقسام المختلفة، وتقديم توصيات استراتيجية مبنية على البيانات لتحسين الكفاءة التشغيلية.

## 🔧 الأدوات المستخدمة
- Power BI / Excel
- بيانات وهمية (Simulated Data) لمستشفى بـ 1000 سرير عبر 8-10 أقسام
